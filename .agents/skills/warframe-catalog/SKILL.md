# Обновление справочного каталога

Загрузи открытый каталог WFCD/warframe-items в `data/catalog.json`, проверь ревизию, дату и лицензию. Каталог — снимок, а не живой источник.

## Когда использовать

- «Обнови каталог», «обнови справочник», «в базе нет каталога».
- После патча игры, когда нужны свежие названия и состав сборки.
- Если skill `warframe-import` сообщил об отсутствии `data/catalog.json`.
- Когда в базе появились игровые ID, которых нет в старом снимке.
- Не используй для обновления инвентаря — это skill `warframe-import`.

## Сначала прочитать

1. `AGENTS.md` — каталог является снимком, личные файлы не меняются.
2. `README.md` — разделы «Команды» и «Ограничения и дисклеймер».
3. `knowledge/sources-research.md` — раздел про открытый каталог и его ограничения.
4. `package.json` — команда `catalog`, если игрок использует npm-алиасы.

## Шаги

1. Объясни игроку, что делает команда: скачивает данные с GitHub (нужна сеть), пишет только `data/catalog.json` и `knowledge/WFCD-LICENSE.txt`, личные файлы и инвентарь не меняет. Получи согласие.
2. Запусти загрузку: `node scripts/import-catalog.mjs` (в шаблоне алиас `npm run catalog`).
   Команда скачивает:
   - ревизию из GitHub API (`commits/master`);
   - файлы `Warframes.json`, `Components.json`, `Resources.json`, `Misc.json` и `i18n/ru.json`;
   - текст лицензии источника.
3. Разбери stdout (JSON): `catalog` (путь), `retrieved_on` (дата в часовом поясе игрока), `timezone`, `revision` (40-символьный SHA коммита), `warframe_entries`, `collection_groups`, `referenced_items`, `unresolved_items`, `russian_names`.
4. Проверь файлы:
   - `data/catalog.json` парсится, `schema_version: 1`;
   - `source.revision` совпадает с выводом и похож на SHA;
   - `retrieved_on` заполнен;
   - `unresolved_item_ids` короткий (пустой или единицы — длинный список сигнализирует о проблеме источника);
   - `knowledge/WFCD-LICENSE.txt` существует и не пуст.
5. Сверь, что личные файлы не изменены: `data/profile.json`, `data/inventory.json`, `data/goals.json`, `data/journal.jsonl` остались прежними.
6. Повторный запуск безопасен: скрипт загружает актуальную ревизию и заменяет снимок только после проверки структуры и успешного чтения временного файла; при той же ревизии результат эквивалентен.
   Автоматического расписания нет — не запускай по таймеру без просьбы.
7. После обновления предложи следующий шаг: skill `warframe-import`, если AlecaFrame доступен и инвентарь устарел; иначе `warframe-status` или `warframe-farm`.
8. Отчитайся: ревизия, дата загрузки, число записей, путь к лицензии, что осталось проверить по Wiki.

## Правила

- Не редактируй `data/catalog.json` и `knowledge/WFCD-LICENSE.txt` вручную.
- Не выдумывай ревизию, дату и число записей — бери только из вывода команды.
- Не считай каталог живым источником: способы получения, ротации и вероятности проверяй по Wiki и таблицам DE.
- Не коммить `data/catalog.json` — он генерируемый и исключён в `.gitignore`.
- Не запускай загрузку без сети или без согласия игрока; не подставляй вручную старый снимок.
- Не меняй скрипты, `AGENTS.md` и `README.md` во время обновления.
- Не обещай, что каталог содержит полные рецепты: в нём только финальная сборка, расход ресурсов на детали проверяй отдельно.

## Отчёт игроку

5–10 строк:
- ревизия и дата загрузки;
- сколько варфреймов, записей и групп коллекции получено;
- сколько ID не разрешено;
- где лежит лицензия;
- что дальше: импорт, сводка или фарм.

Обязательно оговорка, что каталог — снимок и не заменяет проверку источников.

## Если что-то пошло не так

- `fetch failed`, таймаут (45 секунд) или HTTP-ошибка: сообщи адрес и статус, не меняй базу, предложи повторить позже.
- `Invalid catalog revision` или `Unexpected source structure`: источник изменил формат — не обходи проверку, доложи и оставь прежний снимок.
- `Catalog looks incomplete or contains duplicate identifiers`: не применяй результат, сообщи о проблеме источника.
- Нет сети: не подставляй старый файл как новый и не выдумывай данные; объясни, что каталог останется прежним.
- Нет Node.js 20+: объясни требование, не пытайся выполнить команду другим способом.
